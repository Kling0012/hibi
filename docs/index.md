# Hibi

Hibi（日々）は、**自分が PC でしたこと**と **AI エージェントがしたこと**を、ひとつのタイムラインにまとめる個人用の作業記録システムです。

- PC の画面を AI が読み取り、「いま何をしているか」を自動で記録します。
- 「これから○○をする」と宣言すると、終わりは AI が画面の様子から判断して作業時間を残します。
- Claude Code や Codex などの AI が共有記憶に残した作業も、同じタイムラインに時刻付きで並びます。
- その日の記録から、AI が日報とブログ記事を書きます。
- 記録は自分のサーバに集まるので、Mac・Windows のどちらで作業しても、スマホや iPad から同じ記録を見られます。

## 3 つのリポジトリ

Hibi は役割の違う 3 つのリポジトリでできています。それぞれ単独でも動き、組み合わせると全体になります。

| リポジトリ | 役割 | 動く場所 |
|---|---|---|
| [hibi](https://github.com/Kling0012/hibi) | デスクトップアプリ。画面の記録、作業の宣言、閲覧 | 自分の Mac / Windows |
| [hibi-server](https://github.com/Kling0012/hibi-server) | 同期サーバ。記録の集約、検索、日報・ブログの生成、スマホ用の画面 | 常時動いている小さなサーバ 1 台 |
| [hibi-memory](https://github.com/Kling0012/hibi-memory) | AI の共有記憶。AI エージェントが作業内容を残す場所 | 常時動いているサーバ（同期サーバと同じでも可） |

```
 Mac / Windows                         同期サーバ（hibi-server）
┌──────────────────────┐   記録   ┌──────────────────────────────┐
│ Hibi デスクトップアプリ │ ───────▶ │ PostgreSQL + pgvector         │
│  画面の記録・AI 要約     │ ◀─────── │ タイムライン・検索            │
│  作業の宣言            │   閲覧   │ 作業終了の判定・日報・ブログ  │
└──────────────────────┘          │ スマホ / iPad 用の画面 /ui   │
                                   └──────────────▲───────────────┘
                                                  │ 定期取り込み（読み取りのみ）
                                   ┌──────────────┴───────────────┐
 Claude Code / Codex など ───────▶ │ AI の共有記憶（hibi-memory） │
         MCP で記録・検索           └──────────────────────────────┘
```

## できること

| 機能 | 説明 | 詳しく |
|---|---|---|
| 画面の記録 | 画面を 1 秒に 1 枚まで AI に送り、活動の要約と画面の文字を記録 | [デスクトップアプリ](desktop.md) |
| AI の切り替え | Gemini Live（無料枠）を優先し、上限や障害のときは GLM などへ自動で切り替え | [デスクトップアプリ](desktop.md#ai-の接続先) |
| 作業の宣言 | 「これから○○をする」で開始。終わりは AI が判断し、あとから確定・修正できる | [使い方](usage.md#作業の宣言) |
| タイムライン | 作業・各端末・AI ごとのレーンで 1 日を横に並べ、1 か月のヒートマップで振り返る | [使い方](usage.md#タイムライン) |
| 検索 | 意味の近さと文字の一致を合わせたハイブリッド検索 | [同期サーバ API](api.md#検索) |
| 日報 | 毎晩、その日の記録から AI が日報を書く（翌朝に書き直し） | [日報とブログ](blog.md) |
| ブログ | 日報とは別に、読み物としてのブログ記事を AI が下書きする。外部の AI に書かせることもできる | [日報とブログ](blog.md) |
| AI の作業記録 | AI エージェントが共有記憶に残した作業をタイムラインに取り込む | [AI の共有記憶](memory.md) |

## 前提と注意

- **個人用**です。同期サーバと共有記憶には利用者認証がありません。Tailscale などの閉じたネットワークか、localhost の中だけで使ってください。インターネットに直接公開しないでください。
- 画面の内容は、設定した AI の API に送られます。パスワード管理アプリなど、送りたくないアプリは[除外](desktop.md#記録しないアプリ)してください。
- Hibi は [volcengine/MineContext](https://github.com/volcengine/MineContext)（Apache License 2.0）をもとに作り直したものです。元のプロジェクトとは機能も構成も大きく異なります。
