## アプリ

### 起動するたびに設定画面が出る

画像の理解（vision）と構造化出力（structured）のどちらの用途にも、接続先が 1 つもないときに出ます。**設定 → AI** の「用途ごとの優先順」に接続先を入れて保存してください。

### macOS で「壊れているため開けません」と出る

署名していないためです。一度だけ次を実行してください。

```sh
xattr -dr com.apple.quarantine /Applications/Hibi.app
```

### 画面の記録が「停止中」のまま

- **画面の記録** で「記録の対象」を選び、「記録を開始」を押したか確認してください。
- macOS: **システム設定 → プライバシーとセキュリティ → 画面収録** で Hibi がオンか確認し、アプリを再起動してください。
- **設定 → 画面の記録** の「記録を一時停止」がオフか確認してください。
- 最前面のアプリが「記録しないアプリ」に入っていると、その間は記録しません。

### 画面の要約が出ない・遅い

- **設定 → AI** の「接続テスト」で、画像の理解の用途の接続先が届くか確かめてください。
- Gemini の無料枠を使い切ると、自動で次の接続先（GLM など）に切り替わります。次の接続先がないと要約が止まります。
- 要約は 30 秒ごと（ライブ要約の間隔）です。すぐには出ません。

### タイムライン・日報・ブログが「同期サーバに接続できません」

- **設定 → 同期** の URL が `http://<サーバ>:18740` の形か確認してください（末尾の `/ui` は不要）。
- PC が Tailscale につながっているか確認してください。
- ブラウザで `http://<サーバ>:18740/healthz` を開き、`{"ok":true,...}` が返るか確認してください。

### 「未送信」の件数が減らない

**設定 → 同期** の「直近のエラー」を見てください。サーバに届かない間は手元に貯まり、届くようになると自動で送られます。記録が消えることはありません。

## 作業の宣言

### 宣言の入力欄が押せない

同期サーバにつながっていないと宣言できません。入力欄の下の黄色い表示を確認してください。

### 作業が勝手に終わった

AI が「終わった」と判断したか、全端末で 15 分記録がなかったためです。管理画面のタイムラインで作業を押すと、終了時刻を直したり、確定したりできます。判断が早すぎる場合は、サーバの `SESSION_END_THRESHOLD`（既定 0.75）を上げてください。

### 作業がいつまでも終わらない

LLM が設定されていない（`LLM_BASE_URL` が空）と、AI による判定は行いません。15 分の放置か手動の終了だけになります。

## 同期サーバ

### AI の作業が取り込まれない

- 管理画面の **状態** で、取り込みの「最後の成功」と「エラー」を確認し、「今すぐ取り込む」を押してください。
- `AM_BASE_URL` が設定されているか確認してください。
- コンテナから共有記憶に届いているか確認してください。

  ```sh
  docker compose -p hibi exec api python -c "import urllib.request;print(urllib.request.urlopen('http://<memory-host>:8377/health').read())"
  ```

  届かない場合、ホストのファイアウォール（ufw の既定 DROP など）がコンテナからの通信を止めていることがあります。

### 検索で意味の近いものが出ない

- `/healthz` の `embed_pending` が大きいままなら、埋め込みが止まっています。API のログ（`docker compose -p hibi logs api`）を確認してください。
- `EMBED_PROVIDER=fake` のままだと、意味の検索はほぼ効きません。

### 日報やブログができない

LLM に届かないときは作られず、ログに残るだけです。管理画面の日報タブの「今すぐ作成」を押すと、エラーの内容が出ます。

### 埋め込みの次元を変えたい

次元は最初の起動で DB に固定されます。変えるにはバックアップを取ってから DB を作り直してください（[同期サーバ](server.md#バックアップ)）。
