## 应用

### 每次启动都出现设置界面

图像理解（vision）和结构化输出（structured）两个用途都没有任何接入点时会出现。请在**设置 → AI** 的“各用途优先顺序”里加入接入点并保存。

### macOS 提示“已损坏，无法打开”

因为未签名。请执行一次:

```sh
xattr -dr com.apple.quarantine /Applications/Hibi.app
```

### 屏幕记录一直是“停止中”

- 确认在**屏幕记录**里选择了“记录对象”并按了“开始记录”。
- macOS: 确认**系统设置 → 隐私与安全性 → 屏幕录制**中 Hibi 已开启，然后重启应用。
- 确认**设置 → 屏幕记录**的“暂停记录”处于关闭状态。
- 最前台应用在“不记录的应用”列表里期间，不会记录。

### 屏幕摘要不出或很慢

- 用**设置 → AI** 的“测试连接”确认图像理解用途的接入点可达。
- Gemini 免费额度用尽后会自动切换到下一个接入点（GLM 等）。没有下一个接入点时摘要会停止。
- 摘要每 30 秒一次（直播摘要间隔），不会立刻出现。

### 时间线、日报、博客提示“无法连接同步服务器”

- 确认**设置 → 同步**的 URL 形如 `http://<server>:18740`（末尾不需要 `/ui`）。
- 确认电脑已连上 Tailscale。
- 在浏览器打开 `http://<server>:18740/healthz`，确认返回 `{"ok":true,...}`。

### “未发送”条数不减少

请查看**设置 → 同步**的“最近错误”。服务器不可达期间记录攒在本地，恢复后自动发送。记录不会丢失。

## 声明工作

### 声明输入框点不了

未连接同步服务器时无法声明。请查看输入框下方的黄色提示。

### 工作自己结束了

是 AI 判定“已结束”，或所有设备 15 分钟没有记录。在管理界面的时间线里点按该工作，可以修改结束时间或确认。判定过早时，请调高服务器的 `SESSION_END_THRESHOLD`（默认 0.75）。

### 工作一直不结束

未配置 LLM（`LLM_BASE_URL` 为空）时不做 AI 判定。只有 15 分钟闲置和手动结束两种方式。

## 同步服务器

### AI 的工作没有被导入

- 在管理界面的**状态**里查看导入的“最后成功”与“错误”，并按“立即导入”。
- 确认 `AM_BASE_URL` 已设置。
- 确认容器能访问共享记忆。

  ```sh
  docker compose -p hibi exec api python -c "import urllib.request;print(urllib.request.urlopen('http://<memory-host>:8377/health').read())"
  ```

  不可达时，可能是主机防火墙（如 ufw 默认 DROP）拦截了来自容器的通信。

### 搜索搜不到语义相近的结果

- `/healthz` 的 `embed_pending` 一直很大说明嵌入停了。请查看 API 日志（`docker compose -p hibi logs api`）。
- `EMBED_PROVIDER=fake` 时语义搜索基本无效。

### 日报或博客没有生成

LLM 不可达时不生成，只留日志。按管理界面日报标签页的“立即创建”可以看到错误内容。

### 想更改嵌入维度

维度在首次启动时固定到数据库。要修改请先备份再重建数据库（[同步服务器](server.html#备份)）。
